# 오프라인 데모 실행 안내

배포 ZIP을 로컬 디스크의 쓰기 가능한 폴더에 풀고 최상위 `LocalMindStudio.exe`를 실행한다. 설치 프로그램·관리자 권한·.NET 별도 설치가 필요 없는 Windows 11 x64 내부 시연본이다. NVIDIA 드라이버는 PC에 설치돼 있어야 한다.

시연 전에 브라우저 하드웨어 가속·게임·녹화를 종료하고 앱의 ‘모델 SHA-256 검증’을 실행한다. E2B 모델·프로젝터·CPU 임베딩 3개가 포함된다. ‘로컬 서버 시작’을 눌러 사전 준비하면 첫 화면의 모델 로딩 대기를 줄일 수 있다. 단축키는 메모장과 브라우저의 가짜 문장으로 사전에 확인한다. 사용자 문서는 시연에 쓰지 않는다. Wi-Fi 끄기는 사용자가 직접 수행하며 앱의 실제 인터넷 상태를 그대로 소개한다.

‘7분 데모 시작’ → ‘현재 단계 실행’ → ‘다음 단계’ 순서로 화면 안내를 따른다. 단계 이동은 샘플을 준비하며 추론은 실행 버튼으로 시작한다. ‘시연자 노트’로 설명을 펼칠 수 있다. 배정 시간은 참고이며 자동으로 다음 화면으로 넘어가거나 응답을 끊지 않는다. 마지막 화면에서 ‘데모 종료’를 누른다.

| 배정 | 화면 | 확인할 내용 |
| --- | --- | --- |
| 0:00–0:40 | 준비 | 실제 인터넷·외부 연결 수·모델 |
| 0:40–1:25 | 영수증 | 원본과 합계 9,000 대조 |
| 1:25–2:00 | 오류 | 가짜 연결 거부 화면의 진단 |
| 2:00–3:30 | 문서 | 식비 35,000원·출장규정 출처 원문 |
| 3:30–4:30 | 단축키 | 가짜 문장의 변환 팝업·실제 선택은 별도 확인 |
| 4:30–5:30 | 결과 검토 | 이번 데모의 완료 결과와 원문 대조 |
| 5:30–6:15 | 한계 | 1847 × 2963 검산값 5,472,661 |
| 6:15–7:00 | 아이디어 | 적용 업무·검토 담당자·성공 기준 |

실패하거나 응답이 길어지면 ‘취소’를 누른 뒤 ‘안전 재생’을 선택한다. 재생은 저장된 실제 응답이며 노란 ‘재생 결과’ 표시와 기록 시점이 나온다. 현재 추론·성능 측정으로 소개하지 않는다. 모드 변경 시 이전 완료 결과를 비워 실제/재생 결과 혼합을 방지한다.

문서 샘플은 별도 `demo-vault.sqlite`에 색인하므로 일반 문서 금고를 교체하지 않는다. 배포본은 사용자별 LocalAppData에 참고 단가 설정과 문서 금고를 저장한다. 참고 단가는 기본 미입력이다. 창을 최소화하면 트레이로 숨겨지며, 트레이의 ‘종료’ 또는 창 닫기로 서버를 정리한다.

샘플·문구는 `assets/demo/guide.json`에서 관리한다. 아이디어 카드는 사용자 협의용 초안이다. 8개 단계의 `seconds` 합계는 420이며 재생 원본은 해시로 검증한다. `assets/demo/evidence`를 수정하면 안전 재생은 실패한다.

`tools/Verify-OfflinePackage.ps1`로 압축 해제본의 크기·SHA-256을 검사할 수 있다. 이름에 한국어·공백이 있는 경로에서도 실행 파일 기준으로 모델을 찾는다. 외부 공개 전 라이선스·CUDA 배포 조건의 법무 검토가 필요하며 이번 배포본 생성은 외부 공개 승인이 아니다.

3단계의 메모장·브라우저 실제 선택 읽기, 초심자 문서 없는 7분 진행, 연속 3회 7분 시연, 인터넷 물리 단절은 미확인이다. 자동 GUI 순회로 사람의 수용 검사를 대체하지 않는다.
