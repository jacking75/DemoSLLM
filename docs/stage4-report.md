## 범위와 기존 게이트

2026-10-01 사용자의 명시적인 4단계 진행 요청에 따라 구현한다. 3단계의 메모장·브라우저 실제 단축키 입력 검증은 계속 미확인이다. 앞선 보고의 4단계 보류를 이번 구현 요청으로 해제하되 3단계를 소급 통과시키지 않는다. E2B·4096, CPU 임베딩·2048, 장치 전체 7GiB 상한과 인터넷 물리 단절 검증 면제를 유지한다.

초심자 7분 진행과 사람의 품질 수용은 자동 검사로 대체하지 않는다. CI와 working_log.md는 사용하지 않는다. 배포본은 로컬 내부 시연용으로 생성하며 외부 공개·법률 동의·유료 API 호출은 수행하지 않는다.

## 중간 검증

4단계 자동 회귀 16/16과 기존 기능 회귀 40/40을 통과했다. [안전 재생 GUI](stage4-runs/gui-Replay-20261001-005103/result.json)는 8개 화면을 빠르게 3회 순회했고 모델 서버를 시작하지 않았다. 실제 7분 시연이 아니며 사람이 수행한 초심자 게이트로 인정하지 않는다.

시각 진단 PNG는 직접 열었으나 검은 이미지였다. `qwinsta`에서 검사 프로세스 사용자 세션 ID 1은 Disconnected 상태다. 검은 PNG를 정상 레이아웃 증거로 사용하지 않으며 권한·보안·세션을 변경하지 않는다. 최종 시각 검증은 미확인으로 남긴다.

최초 패키지 생성 후 게시 폴더의 언어별 하위 디렉터리 누락을 발견했다. 원본 게시본 전체를 재귀 복사하도록 보완하며 최초 패키지를 덮어쓰거나 삭제하지 않는다. 최종 전달은 보완한 새 패키지다.

## 구현 결과

7분 진행 도우미는 준비·영수증·오류 화면·문서 질의·단축키·결과 검토·한계·아이디어의 8개 화면이다. 합계 420초 배정과 실제 경과 시간을 함께 표시한다. 다음/이전 버튼으로 샘플을 준비하고 실행 버튼으로 실제 작업을 시작한다. 노트 토글·글자 확대·준비 체크리스트를 제공한다. 응답이 길어져도 자동으로 잘라내거나 진행을 완료시키지 않는다.

안전 재생은 SHA-256으로 검증한 기존 E2B·4096 실제 응답 5종을 사용한다. 화면에 노란 재생 표시·기록 시점·모델·현재 추론이 아님을 표시하고 과거 성능 수치는 재생하지 않는다. E 재생은 가짜 입력 직접 전달 기록임을 명시한다. 실제/재생 전환 시 이전 결과를 비워 혼입을 방지한다. 모든 화면의 아이디어 카드는 `assets/demo/guide.json`의 공통 문구를 사용하며 사용자 협의용 초안으로 유지한다.

데모 문서 색인은 LocalAppData의 별도 `demo-vault.sqlite`를 사용한다. 일반 사용자 문서 금고를 교체하지 않는다. 모델 검증·다운로드 대상도 현재 기본 E2B·프로젝터·CPU 임베딩 3개로 맞췄다. E4B 원본·비교 정의는 보존하며 배포본에는 포함하지 않는다.

## 배포본

당시 최종 압축 파일은 로컬 `dist/LocalMindStudio-offline-win-x64-stage4-v2.zip`이다. 대용량 배포 산출물이므로 Git에는 포함하지 않으며 원본 작업 폴더에 보존한다. 압축 해제본의 최상위 `LocalMindStudio.exe`를 실행한다. `.NET 10.0.11` 및 Windows Desktop 런타임을 자체 포함하며 `ko` 등 언어별 하위 디렉터리도 복사했다. 실행 안내·가상 샘플·고정 모델 3개·b11146 CUDA 12.4 런타임·라이선스 고지·검증 도구를 포함한다.

583개 파일의 크기·SHA-256을 검사했다. 파일 합계는 5,526,557,208 bytes, ZIP은 5,527,639,111 bytes이다. ZIP64와 무압축을 사용하며 압축 해제 공간을 별도로 확보해야 한다. ZIP 자체의 SHA-256은 같은 이름의 `.zip.sha256`에 기록한다. 목록의 해시는 우발적인 손상 검사이며 서명된 공급망 인증으로 소개하지 않는다.

NuGet 직접·전이 종속성 9개, .NET·llama.cpp와 하위 구성 요소의 고지, NVIDIA EULA를 포함한다. 고정 E2B 모델 카드는 Apache 2.0을 표기하지만 CPU 임베딩 원본은 별도 Gemma 라이선스이므로 Gemma Terms와 금지 사용 정책을 별도로 포함한다. [라이선스 고지](THIRD_PARTY_NOTICES.md)에 공식 출처와 적용 범위를 기록했다. 약관 동의·로그인·외부 공개는 수행하지 않았다.

## 현재 게이트와 다음 확인

2026-10-01 후속 빌드 요청에 따라 앱 게시 형식을 루트 `bin/LocalMindStudio.exe` 단일 파일로 변경했다. AOT와 ReadyToRun은 끄고 .NET 런타임·관리/앱용 네이티브 DLL을 묶었다. 모델·별도 추론 서버·샘플은 기존 폴더를 사용한다. 일반 `dotnet build`와 빌드 스크립트가 모두 게시까지 수행하며 root bin에 아키텍처·.NET 버전 하위 폴더를 만들지 않는다. 앱 중간 출력은 `src/App.Wpf/obj/app-output/`에 둔다. 기존 다중 파일 ZIP은 이전 검증 기록으로 보존하며 새 패키지 스크립트는 root bin의 EXE를 포장한다.

일반 Debug 빌드와 스크립트 Release 빌드가 경고/오류 0개로 통과했다. Release 결과는 EXE 하나·80,118,587 bytes다. [단일 파일 실제 GUI 검사](stage4-runs/gui-Live-20261001-105851/result.json)는 8개 화면·SQLite 문서 금고·가짜 문장 변환·모드 전환·자식 서버 종료를 통과했다. 해당 실행의 장치 전체 VRAM 관측 최대는 6,417,457,152 bytes·외부 소켓 관측 최대는 0개다. 이 실행은 앞선 표의 4단계 배포본 측정과 별개이며 사람의 7분 시연·실제 다른 앱 선택 읽기 검증으로 대체하지 않는다. 단일 파일 Release 빌드 로그는 [singlefile-release-build.log](singlefile-release-build.log)에 있다.

4단계 기능과 내부 오프라인 배포본은 구현했다. 4단계 전체 게이트는 미통과이다. 연결된 일반 사용자 데스크톱에서 시각 가독성·실제 단축키를 확인하고, 처음 보는 사람이 화면 안내만으로 7분 데모를 완료해야 한다. 7분 시연을 실제로 연속 3회 수행하는 전체 체크도 남아 있다. 경영진 품질 수용·외부 공개 라이선스 검토는 미확인이다. 이 검증에 별도 기준 변경이나 권한 상향을 적용하지 않는다.
