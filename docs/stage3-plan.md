## 범위

E만 구현한다. C/D는 사용자 합의대로 P2 보류이다. 모델·컨텍스트·GPU 상한을 바꾸지 않는다. 선택한 텍스트만 명시적 단축키에 반응해 읽으며 다른 앱의 문서나 사용자 브라우저 프로필을 탐색하지 않는다. 결과를 원래 앱에 자동 입력하지 않는다. 클립보드가 다른 작업으로 바뀌었으면 덮어쓰지 않고 복원 미완료를 표시한다. 데스크톱 접근·전역키 충돌·권한 차이는 숨기지 않는다. 인터넷 단절 검사는 면제·미확인 상태이며 로컬 추론만 사용한다. CI와 작업 로그는 사용하지 않는다.

## 현재 판정

E 구현과 팝업 자체 검사만 완료했다. 실제 메모장·브라우저 선택 입력을 보내는 검사 스크립트가 `SendInput=0, Win32=5`로 중단됐으므로 3단계 게이트는 미통과·4단계는 미시작이다. [보고서](stage3-report.md)에 자체 검사와 시스템 입력 검사를 분리했다. 권한·로그인·UIPI·보호 메타데이터를 임의로 변경하지 않는다.
