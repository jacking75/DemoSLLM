LocalMind Studio
처음 읽어 주세요

이 폴더를 통째로 보관하면 된다. 개발 도구나 명령어를 사용할 필요가 없다. 먼저 아래 순서대로 준비한 뒤 실제 화면이 담긴 사용자 매뉴얼을 따라 사용한다. PDF 매뉴얼은 인쇄할 때 사용한다.

1. PC를 준비한다

  • Windows 11 64비트와 NVIDIA GPU·드라이버가 필요하다. 현재 기본 구성은 그래픽 메모리 8GB를 기준으로 한다.
  • 이 배포본에는 .NET, CUDA 실행 라이브러리, Visual C++ 실행 DLL이 들어 있다. .NET SDK·CUDA Toolkit·Visual C++ 재배포 패키지를 별도로 설치할 필요가 없도록 구성했다. NVIDIA 드라이버는 PC에 설치돼 있어야 한다.
  • 모델 3개는 약 4.16GB다. 배포 폴더와 모델을 둘 공간을 확보한다. 모델이 없는 배포본은 처음 다운로드할 인터넷이 필요하다.

2. 폴더 전체를 압축 해제한다

  1. 받은 ZIP을 오른쪽 클릭하고 “모두 압축 풀기”를 선택한다. ZIP 안에서 바로 실행하지 않는다.
  2. 내 문서 같은 쓰기 가능한 위치에 푼다. Program Files나 읽기 전용 폴더는 피한다.
  3. LocalMindStudio.exe와 assets, tools, third_party 폴더를 함께 보관한다. 모델을 준비하면 models 폴더도 생긴다. EXE 하나만 옮기지 않는다.

3. 모델을 준비하고 시작한다

  1. LocalMindStudio.exe를 더블클릭한다.
  2. 오른쪽 모델 준비 영역에서 “없는 모델 다운로드”를 누른다. 모델이 이미 동봉돼 있으면 “모델 SHA-256 검증”을 누른다. 완료될 때까지 기다린다.
  3. “로컬 서버 시작”을 누른다. 준비 완료 안내가 나오면 채팅이나 이미지·문서 기능을 사용한다. 상세 순서와 화면은 사용자 매뉴얼 5~7쪽에 있다.
  4. 끝낼 때는 창의 X 또는 트레이 메뉴의 “종료”를 사용한다.
모델 없이 화면부터 익히려면 “안전 재생”을 체크하고 “7분 데모 시작”을 누른다. 저장된 과거 예시를 보여 주는 모드이며 내 질문이나 문서를 새로 처리하지 않는다.

4. 문제가 생기면 확인한다

  • 다운로드가 끊기면 인터넷과 디스크 공간을 확인한 뒤 같은 버튼으로 재시도한다. 부분 파일은 이어받기에 사용할 수 있다.
  • DLL 누락 오류가 나오면 EXE만 복사했거나 압축 해제가 빠졌는지 확인한다. 인터넷에서 개별 DLL을 받지 말고 담당자에게 전체 배포본을 요청한다.
  • 서버가 시작되지 않으면 NVIDIA GPU·드라이버와 모델 검증 상태를 확인하고, 오류 문구를 담당자에게 전달한다.
  • 사용자 기록은 프로그램 폴더 바깥의 로컬 앱 데이터에 저장한다. 백업·초기화·기능별 문제 해결은 매뉴얼 21~24쪽에서 확인한다.
이 배포본의 파일 무결성과 정적 DLL 구성은 검사할 수 있으나 새 PC에서의 실제 실행·GPU 추론은 별도 확인이 필요하다. 업데이트는 프로그램을 완전히 종료하고 새 ZIP을 별도 폴더에 압축 해제한다. 이전 모델을 같은 상대 경로로 복사한 뒤 앱의 파일 검증을 실행한다.
