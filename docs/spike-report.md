# 0단계 검증 스파이크 결과

## 현재 결과: B 조건 재측정 완료

후속 B 합의로 Google QAT를 채택하고 C/D를 P2로 보류했다. 오류 이미지 보완 측정은 VRAM 6.436GiB, 오류 답변 3/3 완결로 [0단계 최종 게이트](spike-final.md)를 통과했다. 아래 보완 전·최초 실행 기록은 역사 자료로 보존한다.

두 후보 텍스트·이미지·도구·한국어, CPU 임베딩 및 합성 음성 보조 실측을 완료했다. 최신 결과는 [재측정 보고](spike-round2.md), 미검증 항목 교체안과 대안 두 가지는 [수정안](spike-spec-proposal.md)에 있다.

QAT / ggml-org의 VRAM 피크는 6.665 / 6.811GiB로 7GiB 이하이다. 생성 속도는 약 65 / 62tok/s, 첫 토큰은 0.157초 이하이다. 도구 정확 일치는 각각 16/20(온도 1.0), 15/20(0.2)이며 작은 임베딩 검색 Top1·Top5는 10/10이다. 실제 사용자 음성 품질은 미확인이다. 오류 이미지 답변 잘림과 C/D 처리가 남아 최종 게이트를 선언하지 않는다. 1단계는 시작하지 않았다.
