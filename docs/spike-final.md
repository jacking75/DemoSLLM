## 측정 결과와 판정

근거는 [보완 실측 원본](spike-runs/20260930-163209-vision-190567/summary.json)과 [두 후보 비교](spike-round2.md)이다. E4B·8192 설정·GPU 프로젝터·이미지 상한 1120·사고 비활성화 요청을 유지했다. 원본 응답은 Codex가 검토했으며 경영진의 사용성 평가는 아니다.

| 게이트 | 실제 측정 | 판정 |
|---|---|---|
| VRAM ≤7GiB | 6,910,005,248 bytes (약 6.436GiB), NVML 오류 0 | 충족 |
| 텍스트 동작 | 응답 있음, TTFT 0.147초, predicted_n/predicted_ms 약 69.99tok/s | 충족 |
| 영수증 | 합계 9000, 정상 종료 | 충족 |
| 표 | Sales 120/150, Support 80/90, 정상 종료 | 충족 |
| 오류 화면 | 3회 모두 주소·연결 거부·미실행 서비스 원인 및 조치가 완결된 3줄로 반환, finish_reason=stop | 충족 |
| 긴 입력 이미지 | 실제 prompt_tokens=4735, 합계 9000, 정상 종료 | 추가 확인 |
| C/D 처리 합의 | 사용자 B로 P2 보류, 이번 데모 제외 | 충족 |

오류 답변은 53~55 출력 토큰으로 완료됐다. 3회는 같은 서버·seed에서의 반복이며 독립 세션 재현성으로 일반화하지 않는다. 첫 조치 답변의 포트 변경 제안은 정답 포트 확인 후 적용해야 하므로 UI에서도 결과 검증 안내가 필요하다. 표 JSON은 코드 펜스를 포함하며 추후 파싱·스키마 검증이 필요하다. 텍스트의 절대적 보안 표현은 제품 프롬프트에서 피해야 한다.

**0단계 게이트는 채택한 Google QAT와 C/D 보류 범위에서 통과이다.** 통과 보고 후 1단계 기반 구현을 시작한다. 전체 앱 수용 기준이나 2단계 시나리오 구현의 통과를 뜻하지 않는다.

실제 사용자 음성, 실제 파일 작업, 가득 찬 8K 경계, NVML 샘플 사이 피크, 다른 GPU, 실문서 RAG, 인터넷 단절, 소켓 수치 대조, 강제 종료 해제는 미확인이다. 마지막 세 항목은 1단계 게이트에서 측정해야 한다.
