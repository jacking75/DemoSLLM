## 조건과 원본

Windows 11, RTX 4060(8188 MiB), 드라이버 591.86, Python 3.13.13, CUDA 12.4 b11146(commit 7fe450e19)에서 측정했다. v0.5.0 릴리스가 연결한 바이너리의 실행 버전은 0.5.0-dev이다. [고정 파일·revision·SHA-256](../tools/spike-artifacts.json)을 사용했다.

컨텍스트 8192 설정, 슬롯 1, GPU 프로젝터, 이미지 상한 1120, `chat_template_kwargs.enable_thinking=false` 조건이다. [본 실측 원본](spike-runs/20260930-160024-bc5c95/spike-report.md)과 [합성 음성 원본](spike-runs/20260930-160647-audio-82d91b/summary.json)을 보존했다.

VRAM은 NVML 50ms 주기 장치 전체 사용량이다. 다른 프로세스를 포함하며 샘플 사이 순간 피크는 미확인이다. 긴 이미지 입력은 약 4500 텍스트 토큰을 추가했다. 가득 찬 8192 토큰 경계와 반복 실행 변동성은 미확인이다.

측정한 텍스트 3회는 첫 토큰 2초 이하·서버 생성 20tok/s 이상 목표를 충족했다. 워밍업을 제외하지 않았다. 서버 속도는 predicted_n/predicted_ms이다. 추정치는 같은 모델 /tokenize 출력 content 토큰 수/요청부터 스트림 종료 시간이며 TTFT를 포함하고 추가 tokenizer 요청 시간은 제외한다. 두 속도의 측정 범위는 다르다.

Google QAT 채택을 제안한다. 이번 입력에서 더 빠르고 VRAM이 낮으며 사고 출력이 없었다. 향후 모든 요청에서 off가 보장된다는 뜻은 아니다. ggml-org의 tool-1.0-09는 비활성화 지정에도 reasoning_content를 반환했다.

## Codex 원본 응답 검토

사용자·경영진 품질 승인과 구분한다. [검토 기록](spike-runs/20260930-160024-bc5c95/manual-review.json)에 평가 주체를 남겼다.

- 이미지: 두 후보 모두 영수증 9000, 표 Sales 120/150·Support 80/90, 긴 입력 영수증 합계를 맞췄다. 오류 화면 원인(연결 거부·127.0.0.1:8080·미실행 서비스)은 읽었으나 512 출력 토큰 한도로 조치 설명이 잘렸다. 완결성은 미충족이다.
- 한국어: 두 후보 모두 10개 응답을 반환했다. 01·10이 잘렸고, 01에는 근거 없는 절대적 보안 표현이 있다. 07의 맞춤법 교정은 기대하는 직접 교정과 다르다. 06 JSON에는 코드 펜스가 있다. 사용자 실사용 수용은 미확인이다.
- 도구: 정확 일치 실패는 모두 `.txt` 대신 `txt` 표기이다. 정규화 후 성공률로 바꾸지 않았다. 실제 파일 작업은 실행하지 않았다. content-only 도구 누출 의심은 0/40/후보이며 문제 부재의 일반적 보장은 아니다.
- 임베딩: CPU 설정의 EmbeddingGemma Q8_0으로 규정·질문 각 10개 검색 Top1·Top5 모두 10/10이다. 서버 로그의 실제 임베딩 슬롯은 모델 한계에 따라 2048 토큰이다. 최종 실문서 RAG와 추론 서버 동시 실행 메모리는 미확인이다.

## 합성 음성 보조 실측

설치된 음성은 Heami(ko-KR), Zira(en-US)이다. Heami 문장 5개에 무음을 붙여 각각 30초 PCM16·16kHz·모노 WAV로 측정했다. 두 후보 모두 input_audio 응답 5/5에 성공했다. 피크는 Google 7,127,216,128 bytes, ggml-org 7,224,995,840 bytes로 7GiB 이하이다.

두 후보 모두 첫 문장의 `이 과장`을 `이 과정`으로 오인식했다. 나머지 네 문장은 숫자 표기 차이를 제외하면 핵심 내용을 보존했다. 합성 샘플 검토 4/5이며 실제 사용자 음성 품질·연속 30초 발화는 **미확인**이다.

메모리 제한과 기본 텍스트·이미지 판독 동작은 확인했다. 오류 답변 완결성과 C/D 처리가 남았다. [수정안과 대안 두 가지](spike-spec-proposal.md)를 결정한 뒤 게이트 보완 결과를 보고하고 다음 단계로 넘어간다. 인터넷 단절·외부 연결 수·Job Object 강제 종료 정리는 미확인이고 1단계에서 실제 측정해야 한다.
